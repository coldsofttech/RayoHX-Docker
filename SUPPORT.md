# Support

- **Start with the docs:** the [README](README.md) covers running the image, and the [Docker guide](docs/docker.md) covers folders, settings and exit codes.
- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report form. Say the image tag, your Docker version and platform, and the command you ran, and include the output of `docker run --rm rayohx --version`. For problems in the command itself or the download engine, open the issue in the [RayoHX-CLI](https://github.com/coldsofttech/RayoHX-CLI) or [RayoHX](https://github.com/coldsofttech/RayoHX) repository.
- **Security problems:** see [SECURITY.md](SECURITY.md).
