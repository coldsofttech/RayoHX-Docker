# Security Policy

## Supported versions

Only the latest release receives security fixes.

## What is covered

The RayoHX Docker image and its `Dockerfile`. How it protects secrets and the machine it runs on is described in [docs/security.md](docs/security.md). Problems in the command itself belong to the [RayoHX-CLI](https://github.com/coldsofttech/RayoHX-CLI) repository, and problems in the download engine to the [RayoHX](https://github.com/coldsofttech/RayoHX) repository.

## Reporting a vulnerability

Please do **not** report vulnerabilities in public issues.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the potential impact. You can expect an acknowledgement within a few days and updates as the fix progresses. Once a fix is released, we will credit you if you wish.
